# Hướng dẫn test API bằng Swagger

Hướng dẫn chính đã được hợp nhất vào [Hướng dẫn test toàn bộ API LegacyVault / DigitalVault](Huong-dan-test-toan-bo-API.md).

File tổng hợp bao phủ 93 controller operations, callback OIDC và SignalR; có cấu hình test, quyền, JSON/multipart mẫu, phân trang, status codes, luồng thành công và lỗi cho mọi nhóm chức năng. Đây là một tài liệu độc lập, không cần ghép các hướng dẫn theo đợt cập nhật cũ.

Trang này giữ lại để các liên kết cũ vẫn hoạt động; đọc và cập nhật file tổng hợp khi contract thay đổi.
